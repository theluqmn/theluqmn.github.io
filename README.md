# Luqman's Portfolio

I've built various types of portfolios – complicated ones, simple ones, terminal-looking ones, bla bla bla. I'm done overthinking of my portfolio design, hence I concluded with a oversimplified design with only text and a picture or two lol. Includes my personal blog, the [dispatch](https://theluqmn.github.io/dispatch).

The stack is relatively simple; consisting of only Jekyll, HTML, Tailwind CSS (imported directly to HTML because I'm lazy) and its all deployed on GitHub Pages.

- [portfolio-v2](https://theluqmn.github.io/portfolio-v2) (2025).
